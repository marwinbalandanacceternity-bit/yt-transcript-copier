# YT Transcript Copier

A simple Chrome/Edge extension that adds a **Copy Transcript** button to YouTube's transcript panel. One click extracts the transcript text, removes timestamps, joins lines into clean paragraphs, and copies it to your clipboard.

## Features

- Appears automatically when the transcript panel is open
- Strips all timestamps
- Joins broken lines into readable sentences
- Fixes spacing around punctuation
- Copies cleaned text to clipboard with one click

## Installation

1. Download or clone this repo
2. Open `chrome://extensions` (Chrome) or `edge://extensions` (Edge)
3. Enable **Developer mode**
4. Click **Load unpacked** and select this folder

## Usage

1. Open any YouTube video
2. Click **Show transcript** (under the video description or via the `...` menu)
3. Click the blue **Copy Transcript** button in the transcript panel header
4. Paste the cleaned transcript anywhere
